# Tierras de Nadie: instrucciones del equipo

Leer PROJECT.md, docs/STATE.md y tasks/BACKLOG.md al iniciar.
Este proyecto es independiente de LOOTER. Reutilizar únicamente la metodología de desarrollo.
Usar specs/RULES.md como índice de reglas y fuentes; distinguir decisiones confirmadas, interpretaciones y pendientes.
No inventar ni modificar reglas, balance, héroes o cartas para resolver dudas. Elevar al autor las decisiones de diseño.
Separar lógica de partida, presentación y adaptadores de plataforma.
El orquestador asigna tareas y rutas exclusivas, integra y actualiza memoria. Subagentes no editan simultáneamente archivos compartidos.
Antes de modificar código definir criterios de aceptación. Registrar comprobaciones realmente ejecutadas.
Al terminar actualizar STATE y BACKLOG con resultados, bloqueos y siguiente acción.
Mantener secretos fuera del repositorio. No publicar ni enviar mensajes sin autorización aplicable.
